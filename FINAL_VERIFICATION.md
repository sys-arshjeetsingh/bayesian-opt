## Safety / methodology issues to resolve

1. `tune.py` calls `ALTER SYSTEM RESET ALL` and restarts PostgreSQL. Use a **dedicated disposable cluster**, back up `postgresql.auto.conf`, and never run this on a shared/production server.
2. The `supp.py` deliberately misconfigured setting `max_wal_size=64MB` can be incompatible with PostgreSQL's `min_wal_size` setting; inspect the server's actual settings before running. Do not silently omit failed runs.
3. PostgreSQL restart does **not** guarantee a cold operating-system filesystem cache. The article's claim that every restart starts with a cold buffer cache needs correction.
4. Your article's Ubuntu 24.04 / PostgreSQL 16 numbers cannot be represented as measurements on Windows 11 / PostgreSQL 18. Preserve provenance and replace figures/abstract numbers only after actual measurements.
5. `analyze.py` assumes five or more BO observations for some statistics; it is designed for the complete run, not partial smoke-test logs.
6. If the article states **'default PostgreSQL'**, explain that the scripts explicitly set five selected baseline knobs. These are a paper-defined baseline, not necessarily PostgreSQL's unmodified defaults on the installed server.

## Recommended sequence on Windows 11 (Administrator PowerShell)

From your experiment folder, with PostgreSQL 18 binaries on PATH and password access configured:

```powershell
$D = 'dbname=testdb user=postgres host=localhost'
$P = 'pgbench -h localhost -U postgres testdb'
$R = 'net stop postgresql-x64-18 && net start postgresql-x64-18'
python tune.py --dsn $D --pgbench $P --restart-cmd $R --duration 3 --warmup 1 --repeats 1 --mode baseline --output results/smoke.json
python tune.py --dsn $D --pgbench $P --restart-cmd $R --mode baseline --output results/baseline.json
python tune.py --dsn $D --pgbench $P --restart-cmd $R --mode grid --output results/grid.json
python tune.py --dsn $D --pgbench $P --restart-cmd $R --mode bo --output results/bo.json
python tune.py --dsn $D --pgbench $P --restart-cmd $R --mode validate --winner-file results/bo.json --output results/validation.json
python supp.py --dsn $D --pgbench $P --restart-cmd $R
python analyze.py
python verify_results.py
```

Only execute this sequence after isolating the test cluster and confirming the restart and supplementary configurations are safe for that instance.
